# 01 Asset register

[← Back to README](../README.md)

See [data/asset-register.csv](../data/asset-register.csv): `asset_id, system, item, make_model, location, installed, service_interval, last_service, notes`.

The register covers the **whole house**, grouped by system (heating and DHW, controls, cooling and air, electrical, fire and CO, security, water, energy, lighting and shading, head end and networks, outdoor, appliances). Security items are recorded generically by policy. Where each system is documented in detail: [05 System index](05-system-index.md).
