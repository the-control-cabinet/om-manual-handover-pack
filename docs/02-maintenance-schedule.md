# 02 Planned maintenance

[← Back to README](../README.md)

| Task | Interval | Who |
|---|---|---|
| Boiler service | Annual | Gas Safe engineer |
| Unvented cylinder inspection (relief valves, expansion vessels, high limits) | Annual | G3-qualified installer |
| Expansion vessel pre-charge check (heating) | Annual | Competent person |
| System pressure and inhibitor check | Annual | Homeowner / engineer |
| Evohome and HR92 batteries | As reported / annual | Homeowner |
| Smoke/CO alarm test | Monthly test; replace per manufacturer | Homeowner |
| ESPHome / HA backups verified | Monthly | Homeowner |
| **Disaster-recovery restore test** (timed restore of the latest off-site backup) | Annual | Homeowner (see [head-end health](https://github.com/the-control-cabinet/head-end-health-monitoring)) |
| Sensor calibration checks (pressure, NTCs) | Annual | Homeowner |
